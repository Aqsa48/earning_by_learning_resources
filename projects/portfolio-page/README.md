# Give your finished work a home

Build a small page that explains one project: what it does, how you tested it, and what you learned. The starter is a standalone HTML file with embedded CSS. It has no JavaScript or external dependencies.

## Choose and plan

Choose a project you have actually tried. Name the intended reader and write a short, accurate account of your work before styling the page. Include a public link only if you want visitors to follow it.

## Build

Download or copy `index.html`, open it in a text editor, and replace the example name, introduction, project description, and link. Save the file and double-click it to open it in a browser. Refresh after edits.

The learning hub also has a form that previews your text and downloads `portfolio.html`. Inputs are escaped before entering the template, links must use HTTPS, and the preview is sandboxed. Your text is not stored or uploaded by the builder. The file is downloaded, not automatically published.

## Test

1. Narrow the browser window and check that the content remains readable.
2. Use the Tab key to reach the project link and press Enter.
3. Follow every link and confirm that it opens the intended project.
4. Ask a reader to explain what you built after reading the page.

Use your own account of the work. Avoid invented experience or results.

## Reflect and extend

Record what the reader understood, what confused them, and one next change. Then add another project or publish the page with [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
