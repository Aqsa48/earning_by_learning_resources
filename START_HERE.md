# Choose one useful project

Start with the [CSV quality report](projects/csv-quality-report/README.md). It runs with Python's standard library and includes synthetic data, tests, and expected output.

Use these direct official references when a specific question blocks you:

| Task | Reference |
| --- | --- |
| Read CSV files | [Python csv](https://docs.python.org/3/library/csv.html) |
| Add command-line arguments | [Python argparse](https://docs.python.org/3/library/argparse.html) |
| Write tests | [Python unittest](https://docs.python.org/3/library/unittest.html) |
| Explore a table | [pandas getting started](https://pandas.pydata.org/docs/getting_started/index.html) |
| Make a plot | [Matplotlib quick start](https://matplotlib.org/stable/users/explain/quick_start.html) |

These references support the project. The broader historical collection remains in the README; its shortened links have not all been revalidated.

For a resource suggestion, include its direct URL, intended audience, prerequisites, account/payment requirements, the task you tried, and when you checked it.
