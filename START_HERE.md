# Choose one useful project

Pick one project you can finish and explain:

1. **[CSV quality checker](projects/csv-quality-report/README.md)** — inspect missing cells, exact duplicates, and malformed row lengths. Python standard library only.
2. **[Weather-data visualization](projects/weather-data/README.md)** — plot 14 days of synthetic observations and explain why a missing reading is not zero. Python and Matplotlib.
3. **[Personal portfolio page](projects/portfolio-page/README.md)** — edit a standalone HTML page about one project you actually built. No package installation needed.

Each guide includes a purpose, first-version scope, build instructions, expected results, and an extension. Copy the [project log](PROJECT_LOG.md) to record what you tried and what you will do next.

The [interactive learning hub](WEB_GUIDE.md) offers the same cycle with browser tools and local progress saving. Run it locally or publish it through the repository's GitHub Pages workflow.

## Learn only what the next step needs

| Task | Official reference |
| --- | --- |
| Read a CSV | [Python csv](https://docs.python.org/3/library/csv.html) |
| Add command-line arguments | [Python argparse](https://docs.python.org/3/library/argparse.html) |
| Test a known result | [Python unittest](https://docs.python.org/3/library/unittest.html) |
| Plot measurements | [Matplotlib quick start](https://matplotlib.org/stable/users/explain/quick_start.html) |
| Structure a web page | [HTML basics](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax) |

The broader historical collection remains in the main README; its shortened links have not all been revalidated. For a resource suggestion, include a direct URL, audience, prerequisites, account/payment requirements, what you tried, and when you checked it.
