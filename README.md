# Learn by Doing — Learning & Earning Resources

**Turn something you are learning into something useful you can finish, test, and share.**

A practical starting point for students, early-career researchers, and developers who want to use their skills in a small project. This repository brings together learning resources and a reusable project log.

## How this connects to my book

I'm working on *Learn by Doing*, a book about choosing one meaningful project, making a plan you can start, learning through the problems you meet, and finishing one version.

This repository applies that approach to technical learning:

**CHOOSE → PLAN → BUILD → REFLECT → CHOOSE AGAIN**

The book's approach also works beyond coding. Here, the examples focus on Python, data analysis, and small software tools.

The earning angle starts with usefulness: who has the problem, what would help them, and can they test what you made? A finished project can become a portfolio example or a starting point for a service. Income depends on demand and execution; completing a project does not guarantee paid work.

## Start with one small project

1. **Choose a person and a problem.** Write one sentence: “I am making ___ for ___ so they can ___.”
2. **Define a finished first version.** Pick one visible result and write what you will leave for later.
3. **Plan one short session.** Choose a task you can attempt with the time and tools you already have.
4. **Build and test.** Use a resource below when a specific question blocks you. Ask someone to try the result.
5. **Reflect and return.** Record what worked, what failed, and the next small change.

Copy the **[project log](PROJECT_LOG.md)** into your own notes to begin. There is no fixed daily schedule.

## Project ideas you can adapt

These are starting ideas, rather than completed projects included in this repository.

| If you want to practise… | Try building… | A finished first version |
| --- | --- | --- |
| Python and pandas | A CSV quality report | Summarise missing values and duplicate rows for one public or synthetic dataset. |
| Data visualisation | A small weather-data report | Make three labelled plots and explain one useful finding from public data. |
| Web development | A simple service page | Explain one service, show an example, and give a clear way to make contact. |
| Research workflows | A reproducible analysis example | Include a small public dataset, a script, and instructions someone else can follow. |

Before expanding an idea into paid work, ask a potential user what they currently do, where they lose time, and whether your first version helps.
